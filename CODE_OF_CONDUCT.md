# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the
code and the reasoning, not the person. Harassment of any kind is not
tolerated.

Report unacceptable behaviour to the maintainer at the email address in
[`LICENSE`](LICENSE). Reports are handled privately.
